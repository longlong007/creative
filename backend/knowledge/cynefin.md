# Cynefin 简版：问题属于哪类

先判断情境再选方法。简单：因果清楚，用最佳实践。繁杂：需要分析，用专家和加权评分。复杂：因果事后才清楚，用小试验。混乱：先止血再分析。混乱和复杂时不要假装能算出最优解。

适用：团队争论「我们要不要再做一份分析」的时候。

用法：
1. 问：如果再给两周研究，结论会稳定还是仍会变？
2. 稳定 → 繁杂，值得打分；仍会变 → 复杂，设计安全试验。
3. 人身或资金正在快速失血 → 混乱，先设暂停规则。
4. 简单问题不要过度框架化，直接执行检查清单。

把职业选择当成复杂而非繁杂是常见改进：你无法完全预知入职后的文化，所以用试用、兼职、项目合作来降低一次性跳跃。
