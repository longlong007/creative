## 1. 背景与问题

新生儿家庭每天要记喝奶、睡眠、尿布和身高体重。常见痛点：

1. **记不下来**：夜里喂奶时双手被占用，多步表单容易放弃。
2. **记不到一块**：爸爸、妈妈、老人各用各的备忘录，对不上。
3. **记完用不上**：只有流水账，看不出奶量、睡眠和生长有没有规律。

小芽记的切入点是：先把「记下」压缩到一两下；数据结构按以后做 AI 洞察来设计；家庭开通云开发后共用一本账。

## 2. 产品定位

**一句话**：家庭共用的宝宝成长记录小程序，首页四个大按钮完成高频记录，时间轴和生长曲线做回看，洞察页做本周观察和 DeepSeek 分析。

**不是什么**：

- 不是医疗诊断、用药建议或生长发育筛查工具。
- 不是完整的育儿社区或内容平台。
- 不是必须联网才能用的云服务：未配置云开发时，本机缓存即可记录。

## 3. 目标用户

| 角色 | 诉求 | 使用方式 |
| --- | --- | --- |
| 主要照护人（爸妈） | 夜里也能快速记下喝奶/睡觉/尿布 | 首页大按钮 |
| 共同照护人 | 和另一部手机记同一本账 | 邀请码加入家庭 |
| 关注生长的家长 | 身高体重曲线、本周汇总 | 生长页、洞察页 |
| 开发者/自用部署 | 用测试号或自有 AppID 跑起来 | 微信开发者工具 |

当前不做：医疗机构、月嫂公司多家庭管理后台。

## 4. 产品原则

1. **记下优先于记全**：高频动作一键完成；补记、改时间放在第二层。
2. **默认用上次的量**：喝奶弹出上次毫升，改或不改再点一次保存。
3. **结构可分析**：记录带 `type` / `subtype` / `amount` / `startAt` / `endAt`，而不是纯文本日记。
4. **本地能用、云上能共享**：`cloudEnv` 为空时走微信缓存；填了环境 ID 后走云开发。
5. **AI 是观察不是诊断**：提示词明确禁止诊病、用药、停奶和恐吓。
6. **密钥不进小程序包**：正式环境 DeepSeek Key 只放云函数环境变量。

## 5. 成功标准（当前版本）

| 指标 | 达标定义 |
| --- | --- |
| 高频记录路径 | 睡觉、嘘嘘、便便可 1 次点击写入；喝奶 2 次点击（打开面板 + 保存） |
| 冷启动 | 未建宝宝时进入引导页，填名字/性别/生日即可开始 |
| 本机可用 | 不填 `cloudEnv` 也能完整记录、看时间轴和生长曲线 |
| 家庭共享 | 配置云开发后，6 位邀请码可让另一微信号加入同一家庭 |
| 洞察可用 | 无密钥时可复制提示词；有密钥或云函数时可一键分析 |
| 回归 | `npm test` 覆盖月龄、汇总、睡眠跨夜、洞察 payload、本地建家与快记 |

## 6. 用户旅程

### 6.1 首次使用

```
打开小程序
  → 无宝宝：引导页「给宝宝建一本」
  → 填小名、性别、生日
  → 进入记录首页
```

或：

```
打开小程序 → 「我有邀请码」→ 填 6 位码 → 加入已有家庭
```

本地模式邀请码只存在本机，**不能跨设备加入**。跨设备必须开通云开发。

### 6.2 日常记录

1. 看今日奶量 / 睡眠 / 尿布。
2. 点「喝奶」：选配方奶 / 母乳瓶喂 / 亲喂，选量或分钟，可选「现在 / 5 / 15 / 30 / 60 分钟前」，保存。
3. 点「睡觉」开始，再点「醒来」结束；睡眠中首页有横幅和计时。
4. 点「嘘嘘」或「便便」立即写入。
5. 「身高 · 体重 · 体温 · 辅食 · 补记睡眠」走更多面板。

### 6.3 回看与生长

- 时间轴按天分组，可筛喝奶 / 睡眠 / 尿布 / 生长。
- 生长页切换身高/体重，Canvas 画折线；少于 1 个点时提示「量两次就能看到曲线」。
- 点任意记录可改时间、数值、备注，或删除。

### 6.4 洞察

- 本周本地规则：日均奶量、睡眠、尿布、最长一觉、漏记提示。
- DeepSeek：本周 / 近 7 天 / 近 30 天；可选深度思考。
- 无密钥：复制已整理好的分析提示词，贴到 DeepSeek 网页或其他模型。

## 7. 功能范围

### 7.1 已实现（In Scope）

| 模块 | 能力 |
| --- | --- |
| 引导 | 创建家庭+宝宝；用邀请码加入 |
| 快记 | 喝奶（配方奶、母乳瓶喂、亲喂左/右/双侧）、睡觉开始/结束、嘘嘘、便便 |
| 补记 | 身高、体重、体温、辅食、备注、补记整段睡眠 |
| 时间偏移 | 现在、5/15/30/60 分钟前 |
| 时间轴 | 按天汇总奶量/睡眠/尿布；类型筛选 |
| 生长 | 身高、体重最新值与曲线 |
| 家庭 | 邀请码复制、成员列表、多宝宝切换与新增、编辑宝宝资料 |
| 存储 | 本地 `wx.storage`；云开发 `families/members/babies/records` |
| 洞察 | 本周规则报告；DeepSeek 分析；结果缓存；复制提示词/结果 |
| 备份 | 家庭页导出全部 JSON 到剪贴板 |
| 测试 | Node 逻辑测试，不依赖开发者工具 |

### 7.2 明确不做（当前版本 Out of Scope）

- 推送提醒、喂奶倒计时通知
- 疫苗本、用药、过敏原、产检档案
- WHO / 国内生长曲线百分位对照
- 照片、视频、语音记录
- 账号体系（手机号登录、微信头像昵称授权）
- 家庭成员踢出、退出家庭、转让创建者
- 一个微信号同时加入多个家庭
- 运营后台、数据统计看板
- 付费订阅

## 8. 功能规格摘要

### 8.1 记录类型

| type | 含义 | 主要字段 | 单位 |
| --- | --- | --- | --- |
| milk | 瓶喂 | subtype: formula / breast_bottle，amount | ml |
| breastfeed | 亲喂 | subtype: left / right / both，durationMin | 分钟 |
| sleep | 睡眠 | startAt，endAt（空表示进行中） | 分钟（自动算） |
| diaper | 尿布 | subtype: pee / poop / both | — |
| height | 身高 | amount | cm |
| weight | 体重 | amount | kg |
| temperature | 体温 | amount | °C |
| solid | 辅食 | note | — |
| note | 备注 | note | — |

记录另有：`source`（quick / manual）、`createdBy`、`createdByName`。

### 8.2 首页快记规则

- 睡觉：若已有未结束睡眠，再点则结束，不新开第二条。
- 喝奶默认量：上次瓶喂毫升；若上次是亲喂则默认 120ml；亲喂子类型默认 10 分钟。
- 常用量：瓶喂 60/90/120/150/180/210 ml；亲喂 5/8/10/15/20/30 分钟。
- 保存成功轻震动 + Toast「记下了」。

### 8.3 家庭与权限（产品语义）

- 创建者建家时生成 6 位邀请码（字符集去掉易混的 I、O、0、1）。
- 加入者角色为「家长」。
- 一个 openid 只能属于一个家庭（云函数拒绝重复创建）。
- 一个家庭可有多个宝宝；记录绑定当前宝宝。
- 云端记录拉取：当前宝宝、按 `startAt` 倒序，最多 200 条（10 页 × 20）。

### 8.4 AI 洞察

分析输出固定五段 + 3 条小调整：

1. 奶量规律
2. 睡眠结构
3. 尿布与辅食
4. 生长趋势
5. 可能漏记

默认模型 `deepseek-v4-flash`；允许切换到 `deepseek-v4-pro`（代码白名单）。深度思考开启后超时更长、token 更多。

免责：文案与提示词均声明「不是医生 / 不是诊断」。

## 9. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 首页快记写入后立即刷新；睡眠中每秒刷新进行时长 |
| 可用性 | 云初始化失败自动回退本地，不阻断记录 |
| 兼容 | 微信小程序基础库 3.8.8（项目配置）；自定义 tabBar |
| 安全 | API Key 不入库、不进前端正式包；邀请码大小写不敏感 |
| 隐私 | 分析只上传所选区间的结构化记录摘要，不做长期云端存分析结果 |
| 可测 | 统计、月龄、payload、本地库可在 Node 跑通 |
| 视觉 | 暖米色底 `#F7F1EA`，主色珊瑚 `#E07A5F`，导航标题「小芽记」 |

## 10. 依赖与约束

- 运行环境：微信开发者工具 / 微信客户端。
- 家庭同步：微信云开发（环境 ID 写入 `miniprogram/config.js` 的 `cloudEnv`）。
- AI：DeepSeek Chat Completions；云函数超时建议 60 秒；需配置 `api.deepseek.com` 合法域名（若走前端直连调试）。
- AppID 默认为 `touristappid`，正式发布需换成已认证小程序 AppID。

## 11. 验收清单

- [ ] 新用户可创建宝宝并落到记录首页
- [ ] 喝奶、睡觉、嘘嘘、便便路径符合「一两下」
- [ ] 可补记身高体重体温辅食和整段睡眠
- [ ] 时间轴按天汇总且筛选正确
- [ ] 生长曲线在 ≥1 个点时能画出，≥2 个点有折线
- [ ] 未配云时本地可用；配云后邀请码可加入
- [ ] 洞察页规则报告有四项指标；DeepSeek 在已配置时能返回五段观察
- [ ] 无密钥时可复制提示词
- [ ] `npm test` 通过
- [ ] 分析结果文案不含诊疗承诺

## 12. 风险与假设

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 云数据库权限过宽或过严 | 家庭成员看不到或越权改他人数据 | 见架构说明书安全节；后续应收口到云函数写 |
| 记录只拉最近 200 条 | 大月龄、高频记录的历史缺失 | Backlog：分页或按日查询 |
| 前端直连 DeepSeek | Key 泄漏 | 正式环境只用云函数环境变量 |
| 用户把 AI 当医嘱 | 健康风险 | 固定免责声明与提示词约束 |
| 本地与云数据两套 | 开通云后本机旧数据不会自动迁移 | Backlog：导入/迁移；现有导出 JSON |
