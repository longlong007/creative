# DecideFlow 用户使用说明书

适用版本：MVP v0.1.0  
平台：Web、iOS、Android（同一套操作）

---

## 1. 这是什么

DecideFlow（决断助手）用对话带你做完一次认真的决策：先把问题说清楚，再收集约束、列出选项、对照标准评估，最后给出建议并留下报告。到期后可以复盘当时的假设。

它不是医疗、法律或心理咨询，也不替代专业意见。健康/关系类模板只提供思考框架。

## 2. 使用前准备

1. 服务端已启动（开发者见仓库 README）。
2. 打开应用。Web 开发环境默认连接 `http://localhost:8000`。
3. 准备一个常用邮箱。密码至少 8 位。

没有配置人工智能密钥时，助手仍能按固定流程提问和打分；配置密钥后回复会更自然，并可能引用联网资料。

## 3. 第一次使用

### 3.1 注册

1. 打开应用，进入登录页。
2. 点「没有账号？注册」。
3. 填写称呼、邮箱、密码，点「创建账号」。

### 3.2 填写偏好（必做）

注册后会进入「你的决策偏好」，用于决定助手说中文还是英文、语气，以及首页推荐哪类问题。

| 项 | 建议 |
|---|---|
| 语言 | 中文或 English（影响助手回复，界面目前以中文为主） |
| 语气 | 温暖 / 专业 / 简洁 / 追问 |
| 关注类别 | 至少选一类（职业、财务、健康、关系、购买、生活） |
| 风险偏好 | 保守 / 均衡 / 进取 |
| 决策节奏 | 谨慎会多问几轮，尽快则更快进入下一阶段 |

点「开始使用」进入首页。之后可在右上角设置里改偏好。

## 4. 开始一次决策

1. 首页点右下角「新决策」。
2. 两种方式：
   - 在顶部输入框自己写问题，点「用自定义问题开始」。
   - 或点列表里的模板（例如「要不要换工作」）。关注类别匹配的模板会排在前面。
3. 进入对话页。顶部一排阶段：澄清 → 收集 → 选项 → 评估 → 建议 → 已记录。

按助手的问题回答即可。可以说「就这些」「评分可以」来推进。节奏选「尽快」时，大约每阶段一轮就会往下走。

发送失败时，你刚打的字会留在输入框，改完再发。

## 5. 看报告并记下选择

当阶段来到「建议」（或首页看到进行中的决策已接近结束）：

1. 点右上角「报告」，或从首页进入该决策的报告。
2. 阅读 Markdown 报告：问题、标准、约束、选项得分、建议和风险。
3. 在下方选一个选项，或在备注里写自定义选择。
4. 点「记录决策并安排复盘」。默认 14 天后会出现在复盘列表。

记录之后，这条对话不能再继续聊。需要新问题请再开一次决策。

## 6. 复盘

首页若出现「有 N 条决策该复盘了」，或点右上角回放图标：

1. 打开到期列表。
2. 进入报告回顾当时写了什么。
3. 在对话框写下：假设还成立吗？实际结果如何？
4. 点「完成复盘」。该条会从到期列表消失，并出现在首页「已记录」中（状态为已复盘）。

未到期的决策不会出现在复盘列表。

## 7. 首页怎么读

- **进行中**：还没记录最终选择，点进去继续聊（若已到建议阶段会进报告）。
- **已记录**：已保存选择；可打开报告查看。
- 标题旁的阶段名表示进行到哪一步。

## 8. 退出登录

设置 → 退出登录。下次需要重新登录。未完成的决策仍保存在账号下。

## 9. 常见问题

**问：助手有时像在套模板？**  
未配置大模型密钥时，系统用内置教练按阶段提问，仍会引用知识库里的方法名称。这是预期行为。

**问：为什么不让我改已经记录的选择？**  
记录是当时的快照，便于日后复盘。若情况变了，请新开一次决策。

**问：知识库用了哪本书的原文吗？**  
没有。里面是原创的方法摘要（加权评分、预验尸、机会成本等），避免版权问题。

**问：健康或感情问题能替我做决定吗？**  
不能。请把输出当作思考清单，重要事项咨询专业人士。

**问：忘记密码怎么办？**  
MVP 未提供找回密码，需使用注册时的邮箱密码或重新注册（数据不迁移）。

## 10. 隐私简述

- 对话原文、报告、偏好保存在服务端你的账号下。
- 其他用户无法读取你的决策。
- 应用内不保存大模型厂商密钥。
