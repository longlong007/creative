# 小芽记用户使用说明书

适用版本：1.0.0  
产品：家庭共用的宝宝成长记录微信小程序

分析结果和本周观察来自你们自己记下的数据，**不是医疗诊断**。宝宝身体不舒服请看医生。

---

## 1. 它能帮你做什么

- 用大按钮记下喝奶、睡觉、嘘嘘、便便
- 补记身高、体重、体温、辅食、备注
- 按天回看，看身高体重曲线
- 家人用邀请码记同一本账（需要开通云开发）
- 看本周奶量和睡眠观察；有条件时用 DeepSeek 分析规律和漏记

## 2. 第一次打开

1. 用微信开发者工具导入项目，或由家人发给你的小程序入口进入。
2. 若还没有宝宝，会看到「小芽记」欢迎页。
3. 点 **给宝宝建一本**：
   - 写小名
   - 选女孩 / 男孩 / 先不填
   - 选生日
   - 点 **开始记录**
4. 若家里已经有人建好了，点 **我有邀请码**，输入 6 位码。

未开通云开发时，数据只在这台手机的微信里。邀请码也只在这台手机有效，**别的手机填码加不进去**。

## 3. 底部四个入口

| Tab | 用途 |
| --- | --- |
| 记录 | 日常快记、今日汇总、刚才记下的 |
| 时间轴 | 按天翻历史，可筛选类型 |
| 生长 | 身高体重数字和曲线 |
| 家庭 | 邀请码、家人、切换宝宝、导出备份 |

右上角或首页的 **洞察** 会打开分析页（不在底部 Tab 里）。

## 4. 怎么记（记录页）

页面上方是宝宝名字和月龄，中间是今日奶量、睡眠、尿布。有进行中的睡眠时，会出现「宝宝睡着了」横幅，可直接点 **醒来**。

### 4.1 喝奶

1. 点橙色 **喝奶**（会带出上次的毫升）。
2. 选类型：配方奶、母乳瓶喂、亲喂·左 / 右 / 双侧。
3. 点常用量，或自己输入。亲喂单位是分钟。
4. 需要补记刚才那一顿时，选「5 分钟前」等到「1 小时前」。
5. 点保存。成功会提示「记下了」。

### 4.2 睡觉

- 没在睡：点 **睡觉** → 开始计时。
- 正在睡：点 **醒来** 或点横幅 → 自动算时长。

不会同时开两段「进行中」的睡眠。若忘了点醒来，请到时间轴点开那条，或用「补记睡眠」另记一段（进行中的那条仍在，记得改掉或删掉，避免重复）。

### 4.3 尿布

点 **嘘嘘** 或 **便便** 立刻保存。若一次既有嘘嘘又有便便，目前首页没有「都有」按钮；可先记一个，再在编辑里改不了子类型——当前编辑页主要改时间、数值和备注。需要「都有」时，可用两次快记，或等后续版本补入口（见 Backlog）。

### 4.4 身高、体重、体温、辅食、补记睡眠

点首页 **身高 · 体重 · 体温 · 辅食 · 补记睡眠**：

- 身高 / 体重 / 体温：填数字保存
- 辅食、备注：可写一句话
- 补记睡眠：进入单独页，选入睡和醒来的日期时间，醒来必须晚于入睡

生长页也可以直接加身高或体重。

### 4.5 改错或删掉

点「刚才记下的」或时间轴里的一条，可改时间和备注（有数值的也能改数字）。点删除需确认，**不能恢复**。

## 5. 时间轴

顶部筛选：全部、喝奶、睡眠、尿布、生长。

每一天会显示当天奶量、睡眠、尿布的一句话汇总。点某条可编辑。

睡眠如果跨了午夜：时长会拆进对应的自然日汇总里，但整条记录列在「睡着的那天」下面。

## 6. 生长

切换「体重 / 身高」。至少有一个测量点会画图；点很少时曲线几乎是水平的。建议固定时间段（例如洗澡后）再量，方便对比。

这里没有国家标准百分位，不能用来判断「超标」或「落后」。

## 7. 家庭

- **家庭邀请码**：点复制发给家人。开通云开发后，家人在欢迎页或本页「我要加入别人的家」输入即可。
- **这本账里的人**：显示称呼和角色（创建者 / 家长）。目前不会自动用微信昵称。
- **宝宝**：点名字切换当前宝宝；「再添加一个宝宝」可记二宝。记录是按当前宝宝分开的。
- **编辑**：改小名、性别、生日。
- **导出全部记录（JSON）**：复制到剪贴板，请自行粘贴到备忘录或文件。导入功能还没有做在界面上。

本机模式提示：把云开发环境 ID 填进 `config.js` 后，家人才可以用这个码加入。这需要会改项目的人操作，普通家长向部署者确认即可。

## 8. 数据洞察

路径：首页右上角 **洞察**，或家庭页 **DeepSeek 分析本周记录**。

### 8.1 本周速览（不用密钥）

自动统计本周一到今天的：

- 日均奶量、日均睡眠、日均尿布、最长一觉
- 亮点（例如间隔、漏记提醒）
- 「可以试着做」的建议

### 8.2 用 DeepSeek 分析（需要配置）

1. 选区间：本周 / 近 7 天 / 近 30 天。
2. 需要更细时打开 **深度思考**（更慢）。
3. 点 **用 DeepSeek 分析**。
4. 可读完后点 **复制这篇分析**。

没有配置时，按钮会提示如何接密钥。你仍可点页面下方 **复制分析提示词**，粘贴到 DeepSeek 网页或其它对话 AI。

同一宝宝、同一区间、同一思考开关下，上次结果会记在手机里，再进来能看到，避免重复花接口费用。换区间或开关后缓存分开。

请记住：

- 没记过的天会被当成「可能漏记」，不一定是宝宝没喝奶。
- 不要按分析自行停奶、用药或停诊。

## 9. 给部署者的简短说明

家长不需要看本节。把小程序交给家人用之前：

1. 导入微信开发者工具，AppID 正式发布前换成已认证账号。
2. 只自己用：不填 `cloudEnv`，每人一部手机各记各的。
3. 家人共用：开通云开发 → 填环境 ID → 建集合 `families` `members` `babies` `records` → 部署云函数 `login` `createFamily` `joinFamily` `aiAnalyze` → 给 `aiAnalyze` 配 `DEEPSEEK_API_KEY`。
4. 密钥不要发给家长，不要写进小程序代码后上传。

细节见仓库根目录 `README.md`。

## 10. 常见问题

**Q：为什么家人加不进来？**  
A：本机模式不能跨设备。需要云开发，且邀请码 6 位、字母数字、不分大小写。码输错会提示「邀请码不对」。

**Q：数据会丢吗？**  
A：本机模式卸载微信或清缓存可能丢失。请偶尔在家庭页导出 JSON。云模式存在微信云开发，仍建议重要节点自己留备份。

**Q：能记两个宝宝吗？**  
A：能。在家庭页添加并切换。首页和时间轴只显示当前宝宝。

**Q：睡眠计时关小程序会停吗？**  
A：开始睡觉会写成一条没有结束时间的记录。再打开点醒来即可。计时横幅只在记录页前台每秒刷新，不影响已写入的开始时间。

**Q：AI 要收费吗？**  
A：DeepSeek 按上游平台计费，本小程序不内置支付。不配密钥时可用复制提示词，费用发生在你使用的网页或 API 账号上。

**Q：记录能同步到几部手机？**  
A：同一云环境、同一家庭邀请码下的微信用户。一个微信号创建家庭后，云函数不允许再创建第二个家；加入逻辑以邀请码为准。
