# 文档目录

本目录为 DecideFlow MVP v0.1.0 的正式文档。Markdown 与同名 `.docx` 内容一致。

| 文件 | 说明 |
|---|---|
| 01-PRD产品需求文档 | 目标、范围、功能与非目标 |
| 02-架构说明书 | 分层、端口、数据流、部署与安全边界 |
| 03-系统详细设计 | 表结构、状态机、教练、RAG、客户端页面 |
| 04-接口文档 | `/api/v1` 请求响应与错误码 |
| 05-用户使用说明书 | 给使用者的操作说明 |
| 06-开发记录 | 决策、验证、踩坑 |
| 07-Backlog | 已完成 / 下一迭代 / 债 |

设计草稿仍保留在 `docs/superpowers/`，以本目录为准对外同步。

重新生成 Word 文件：

```bash
python3 doc/generate_docx.py
```
