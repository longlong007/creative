# DecideFlow 接口文档

| 项 | 内容 |
|---|---|
| 版本 | v1（`/api/v1`） |
| Base URL | `{API_BASE}`，本地默认 `http://localhost:8000` |
| 数据格式 | JSON，UTF-8 |
| 鉴权 | `Authorization: Bearer <access_token>`（除注册、登录、健康检查） |
| 日期 | 2026-08-31 |

OpenAPI 可在服务启动后访问 `/docs`（FastAPI 自动生成）。本文与代码 `backend/app/schemas.py`、`backend/app/api/*.py` 对齐。

---

## 1. 约定

### 1.1 错误

| HTTP | 场景 |
|---|---|
| 401 | 未带 Token、Token 无效、用户不存在 |
| 404 | 决策不属于当前用户（含故意不暴露是否存在） |
| 409 | 邮箱已注册；未到 recommend 就 record；已 recorded 仍发消息；状态不允许复盘 |
| 422 | Pydantic 校验失败（密码过短、缺字段等） |

错误体一般为 `{"detail": "..."}`。422 时 `detail` 可能为校验数组。

### 1.2 通用枚举

**stage：** `clarify` | `collect` | `options` | `evaluate` | `recommend` | `recorded`

**status：** `active` | `recorded` | `reviewed`

**message.role：** `user` | `assistant` | `system`

**category：** `career` | `finance` | `health` | `relationship` | `purchase` | `life`

## 2. 健康检查

### GET `/health`

无需鉴权。

**响应 200**

```json
{ "ok": true, "vectors": 10 }
```

`vectors` 为当前向量库条数。

## 3. 认证

### POST `/api/v1/auth/register`

**请求**

| 字段 | 类型 | 约束 |
|---|---|---|
| email | string | Email |
| password | string | 8–128 |
| display_name | string | 可选，≤80 |

**响应 200**

```json
{ "access_token": "<jwt>", "token_type": "bearer" }
```

**409** `email already registered`

注册后 `onboarding_done=false`，偏好为默认值。

### POST `/api/v1/auth/login`

**请求：** `{ "email", "password" }`

**401** `invalid credentials`

**响应：** 同 register。

### GET `/api/v1/auth/me`

**响应 200 UserOut**

```json
{
  "id": "uuid",
  "email": "ada@example.com",
  "display_name": "Ada",
  "onboarding_done": true,
  "preferences": {
    "language": "zh",
    "tone": "warm",
    "categories": ["career"],
    "risk_tolerance": "medium",
    "decision_speed": "balanced"
  }
}
```

## 4. 偏好与模板

### PUT `/api/v1/users/me/preferences`

请求体即 Preferences 全量（非 patch）。成功后 `onboarding_done=true`。响应 UserOut。

| 字段 | 允许值 |
|---|---|
| language | zh, en |
| tone | professional, warm, concise, socratic |
| categories | 字符串数组 |
| risk_tolerance | low, medium, high |
| decision_speed | careful, balanced, fast |

服务端当前不做枚举强制校验，非法值会按默认逻辑降级（如语速未知当 balanced）。

### GET `/api/v1/templates`

Query：`category` 可选。

**响应 200** `TemplateOut[]`

```json
{
  "id": "career-switch",
  "category": "career",
  "title": "要不要换工作",
  "prompt": "我在考虑换工作。当前角色、新机会和顾虑如下：",
  "suggested_criteria": ["成长空间", "薪酬总包", "工作强度", "稳定性"]
}
```

排序：用户 categories 命中的类别在前，`blank` 最后。

## 5. 决策

### POST `/api/v1/decisions`

创建并进入 clarify，附带一条助手开场白。

**请求 DecisionCreate（均可空）**

| 字段 | 说明 |
|---|---|
| title | 标题 |
| category | 类别 |
| template_id | 模板 id |
| problem | 用户问题原文，写入 problem_statement |

缺省时：标题取模板标题或问题前 40 字或「新的决策」；类别取模板或 `life`。

**响应 200 DecisionOut**（结构见 5.4）。

### GET `/api/v1/decisions`

当前用户列表，`updated_at` 降序。

**响应 200 DecisionSummary[]**

```json
{
  "id": "uuid",
  "title": "要不要换工作",
  "category": "career",
  "stage": "clarify",
  "status": "active",
  "review_at": null,
  "updated_at": "2026-08-31T08:00:00+00:00"
}
```

### GET `/api/v1/decisions/{id}`

完整 DecisionOut。404 若非本人。

### GET `/api/v1/decisions/{id}/report`

当前与 GET 详情相同（返回 DecisionOut，内含 `report_markdown`）。预留独立报告 URL。

### POST `/api/v1/decisions/{id}/messages`

**请求：** `{ "content": "..." }`，1–8000 字。

**响应 200 ChatResponse**

```json
{
  "decision": { "...DecisionOut" },
  "assistant_message": {
    "id": "uuid",
    "role": "assistant",
    "content": "我听到了。...",
    "stage": "collect",
    "extra": {
      "retrieved": [
        { "id": "weighted-scoring", "title": "加权评分 Weighted Scoring", "text": "...", "score": 0.42 }
      ],
      "web": [],
      "degraded": false
    },
    "created_at": "2026-08-31T08:01:00+00:00"
  }
}
```

**409** `decision already recorded`

MVP 为一次请求一次完整回复，无 SSE。后续可加 `stream=true` 而不改 workspace。

### POST `/api/v1/decisions/{id}/record`

仅 `stage=recommend`。

**请求 RecordDecisionRequest**

| 字段 | 类型 | 说明 |
|---|---|---|
| option_id | string? | 对应 workspace.options[].id |
| custom_choice | string? | 自定义标签；无 option 命中时用此作为 label |
| notes | string? | 备注 |
| review_in_days | int | 默认 14，1–365 |

**409** `not ready to record`

成功后 status=recorded，生成最终报告，写入 system 消息。

## 6. 复盘

### GET `/api/v1/reviews/due`

`status=recorded` 且 `review_at <= now`。按 review_at 升序。返回 DecisionSummary[]。

### POST `/api/v1/reviews/{decision_id}/complete`

**请求：** `{ "notes": "..." }`，notes 可空（空则消息内容为「已复盘」）。

**409** `review not due`（status 不是 recorded）

成功：status=reviewed，写入 reviewed_at、review_notes。

## 7. DecisionOut 完整字段

```json
{
  "id": "uuid",
  "title": "string",
  "category": "career",
  "template_id": "career-switch",
  "stage": "recommend",
  "status": "active",
  "workspace": {},
  "report_markdown": "# 决策报告：...",
  "review_at": null,
  "reviewed_at": null,
  "review_notes": "",
  "messages": [],
  "created_at": "...",
  "updated_at": "..."
}
```

workspace 形状见《系统详细设计》§1.4。

## 8. JWT

- 算法 HS256
- 载荷 `sub` = user.id，`exp` = 签发 + `ACCESS_TOKEN_EXPIRE_MINUTES`（默认 10080 分钟 = 7 天）
- 无 refresh token

## 9. 调用示例

```bash
TOKEN=$(curl -s http://localhost:8000/api/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"ada@example.com","password":"password123","display_name":"Ada"}' \
  | python3 -c 'import sys,json; print(json.load(sys.stdin)["access_token"])')

curl -s http://localhost:8000/api/v1/users/me/preferences \
  -X PUT -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"language":"zh","tone":"warm","categories":["career"],"risk_tolerance":"medium","decision_speed":"fast"}'

DID=$(curl -s http://localhost:8000/api/v1/decisions \
  -X POST -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"template_id":"career-switch","problem":"换工作还是留下"}' \
  | python3 -c 'import sys,json; print(json.load(sys.stdin)["id"])')

curl -s http://localhost:8000/api/v1/decisions/$DID/messages \
  -X POST -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"content":"我更看重成长"}'
```
