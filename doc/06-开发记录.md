## 1. 背景

仓库初始只有一句 README。需求：Flutter 覆盖 iOS/Android/Web；用对话引导决策；RAG + Pinecone；可联网；注册后先填偏好；模板或自定义问题；阶段式引导；保存原文与报告；定期复盘。约束：只做 MVP，架构能演进。

## 2. 关键决策

| 决策 | 选择 | 原因 |
|---|---|---|
| 客户端 / 服务端 | Flutter 薄客户端 + FastAPI | RAG/LLM/密钥不能进 App；三端一套 UI |
| 数据库 | SQLAlchemy + 默认 SQLite | `DATABASE_URL` 可换 Postgres，无运维负担 |
| 向量库 | Protocol：Pinecone 或本地 JSON | 无密钥也能开发测试 |
| 嵌入 | OpenAI 或稳定哈希 256 维 | 测试可复现；禁止与 1536 维混写同一 index |
| 教练 | LlmCoach 失败则 HeuristicCoach | 演示与 CI 不依赖付费 API |
| 联网 | Tavily，失败静默 | 收集/评估阶段可选，不阻断 |
| 认证 | 邮箱密码 + JWT HS256 | MVP 不做 OAuth |
| 密码哈希 | PBKDF2-SHA256 | 避免 bcrypt 原生绑定问题 |
| 聊天传输 | 一次 JSON 往返 | 不做 SSE，接口可加 |
| 知识库 | 10 篇原创摘要 | 满足 RAG，避免书摘版权 |
| 复盘提醒 | 到期列表，非系统推送 | 推送需证书与厂商通道 |
| 应用工厂 | `create_app(settings)` | 测试注入临时库，避免全局单例 |

## 3. 实施顺序

## 6. 开发中踩过的点

1. **JWT 密钥来源**：`create_access_token` 曾读全局 `get_settings()`，与测试里传入的 Settings 不一致。改为使用 `request.app.state.settings.secret_key`。
2. **应用单例**：模块级 `app = create_app()` 会在 import 时建真实库。改为 uvicorn `--factory`。
3. **循环依赖**：决策路由不能从 `main` 取 orchestrator，改为 `app.state` + Depends 覆盖。
4. **due reviews 漏导入**：`utcnow` 未导入导致 500，已补。
5. **Flutter 3.47**：`RadioListTile.groupValue` 已弃用，改为 ListTile + 图标选择。
6. **知识库版权**：不入库任何书籍原文，只写原创方法说明。

## 7. 环境与第三方

运行 MVP **可以不配** 下列密钥：

- `OPENAI_API_KEY`：对话 + embeddings
- `PINECONE_API_KEY`：云向量（须同时有 OpenAI 嵌入，维度才一致）
- `TAVILY_API_KEY`：联网

Python：3.12。Flutter：3.47.0 stable。

## 10. 后续开发建议

1. 生产必须更换 `SECRET_KEY`，收紧 CORS，SQLite 换 Postgres。
2. 配置 OpenAI + Pinecone 后执行 `python3 scripts/ingest.py` 重建向量。
3. HashEmbedder 仅用于开发，不要与生产 embedding 混用。
4. 新阶段或新模板优先改 `domain/stages.py` 与 `templates.py`，保持 API 形状稳定。
