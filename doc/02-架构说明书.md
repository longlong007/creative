| 项 | 内容 |
|---|---|
| 版本 | MVP v0.1.0 |
| 日期 | 2026-08-31 |
| 对应代码 | `app/`（Flutter）+ `backend/`（FastAPI） |

---

## 1. 设计原则

1. **客户端薄、服务端厚**：LLM、RAG、联网、报告都在后端，便于审计和换模型。
2. **端口隔离外部依赖**：向量库 / 嵌入 / LLM / 搜索均为 Protocol，无密钥时本地回退，有密钥时替换实现。
3. **对话与工作区分离**：消息是事实源；workspace JSON 是给 UI 和报告用的投影。
4. **MVP 可跑、结构可演进**：默认 SQLite + 本地向量；`DATABASE_URL` 与 Pinecone/OpenAI 环境变量即可升级。

## 2. 逻辑架构

```
┌─────────────────────────────────────────────┐
│  Flutter：iOS / Android / Web               │

└──────────────────┬──────────────────────────┘
                   │ HTTPS JSON  /api/v1
┌──────────────────▼──────────────────────────┐
│  FastAPI create_app()                       │
│  ┌─────────┐ ┌──────────┐ ┌──────────────┐  │
│  │ api     │ │ domain   │ │ services     │  │
│  │ 鉴权DTO │ │ 阶段/报告 │ │ RAG/LLM/搜索 │  │
│  └─────────┘ └──────────┘ └──────┬───────┘  │
│                                  │          │
│  SQLAlchemy  向量库  LLM  联网   │          │
└──────────────────────────────────┼──────────┘
                                   │
     SQLite/Postgres    LocalJSON/Pinecone    OpenAI    Tavily
```

## 3. 仓库结构

| 路径 | 职责 |
|---|---|
| `app/lib/features/*` | 按页面划分的 Flutter 功能 |
| `app/lib/state/session.dart` | 会话、JWT、全部 API 调用 |
| `app/lib/models/models.dart` | 与后端 DTO 对应的解析 |

| `backend/tests/` | pytest |

## 4. 后端分层

| 层 | 允许依赖 | 禁止 |
|---|---|---|
| api | schemas、domain 枚举、services 编排、models | 直接 new OpenAI/Pinecone |
| domain | 无基础设施 | 数据库、HTTP、文件系统 |
| services | domain + 第三方 SDK | 拼 HTTP 响应细节 |
| models / db | SQLAlchemy | 业务话术 |

`create_app(settings)` 工厂在启动时：建表、解析知识库路径、ingest（若向量库为空）、注入 `ChatOrchestrator`。测试用临时 SQLite 和临时向量文件构造独立 app。

## 5. 外部端口

| 端口 | 生产实现 | 回退实现 | 切换条件 |
|---|---|---|---|
| Embedder | OpenAI `text-embedding-3-small`（1536 维） | HashEmbedder 256 维 | `OPENAI_API_KEY` |
| VectorStore | Pinecone index `decideflow-knowledge` | `LocalVectorStore` JSON + 余弦 | `PINECONE_API_KEY` **且** 已有 OpenAI（避免维度混用） |
| Coach | `LlmCoach`（JSON 响应，失败降级） | `HeuristicCoach` | `OPENAI_API_KEY` |
| WebSearch | Tavily | NoOp（空结果） | `TAVILY_API_KEY` |

哈希嵌入与 OpenAI 嵌入不得写入同一 Pinecone index。

## 6. 客户端架构

- **路由**：`go_router`，`refreshListenable: session`。未登录 → `/login`；已登录未 onboarding → `/onboarding`。
- **状态**：单一 `SessionController`（ChangeNotifier）持有 token、UserProfile、API。
- **持久化**：`shared_preferences` 仅存 `access_token`。
- **API Base**：编译期 `--dart-define=API_BASE=...`，默认 `http://localhost:8000`。
- **页面**：login / register / onboarding / home / templates / chat / report / reviews / settings。

客户端不实现阶段机，只渲染后端返回的 `stage`、`workspace`、`messages`。

## 7. 数据流（一次发言）

```
用户输入
  → POST /decisions/{id}/messages
  → 校验归属与未 recorded
  → RAG.search(title + content)
  → 若 collect/evaluate：WebSearch（失败忽略）
  → Coach.reply(workspace, history, prefs, retrieved)
  → 落库 user/assistant 两条 Message
  → 更新 Decision.stage / workspace / report_markdown
  → 返回 ChatResponse
```

## 8. 部署视图（MVP）

单机即可：

1. `uvicorn app.main:create_app --factory --port 8000`
2. Flutter Web 或移动端指向该 API
3. CORS 默认 `*`，生产应收紧 `CORS_ORIGINS`

后续：API 与 SQLite/Postgres 分开；Flutter 打商店包；向量与 LLM 走托管服务。

## 9. 安全边界

- 鉴权：Bearer JWT，密钥来自 `app.state.settings.secret_key`。
- 授权：所有决策查询带 `user_id`，跨用户返回 404（避免枚举确认）。
- 密钥：不打包进 Flutter。
- 密码：PBKDF2-SHA256（12 万次），非可逆。
